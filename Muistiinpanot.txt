static; (säilyy paikallaan)

= mahdollistaa päällekkäiset ja liikkumattomat elementit
-z-index = layerit kuvankäsittelyssä. ns. kalvoja päällekkäin.

static = kulkee normaalivirran mukana, default PAITSI jos elementissä on jokin osa määritelty jo ylempänä/alempana.

relative = kulkee normaalivirran mukana, tekee elementistä absolute lapsen containing blocking. hyvä visuaalisiin siirtoihin.

containing block = viewport johon kaikki positioidut elementit suhteutetaan.

fixed = ei kulje normaalivirran mukana, pysyy paikoillaan sivua scrollatessa (esim huomio tai navigointipalkki). suhteessa viewporttiin.

sticky = pysyy normaalisti mukana, kunnes määritelty reuna tulee ja se jää siihen reunaan. Tarvitsee top tai z-index rajan.

absolute = ei kulje normaalivirran mukana, aina siinä mihin määritelty. suhteessa vanhempi elementtiinsä, joka on relative/fixed. (top: 50%; left 50%; transform: translate (-50%, -50%;))

z-index: 0-100 arvoilla. (mitä suurempi arvo, niin sitä pinnemmalla se on.)

inset = offsetin nopeampi versio.
loogiset versiot: 
-inset-block start/end (lohkon alku ja loppu)
-inset-inline-start/end (seuraa tekstin kirjoitus suuntaa)

!!visuaalinen sijainti ei saa rikkoa loogista lukemis ja fokus järjestystä!!

    11. Vertaa toteutunutta tulosta odotettuun. (Testaa ainakin tavallinen tilanne ja olennaiset rajatapaukset. Esim. mukana on sekä saatavilla olevia että loppuneita tuotteita; kaikki ovat loppuneet; taulukko on tyhjä.)

BOOLEAN:
Boolean = vain true/false arvot.

VERTAILU:
esim.

    concole.log(10 > 5); //true (ehto täyttyy)

    console.log(7 === 7); //true (ehto täyttyy)
eli onko vasen arvo suhteessa oikeaan true or false?

vertailuoperaattorit:
    == : Yhtäsuuruus: voi muuntaa arvojen tyyppejä ennen vertailua (5 == '5', eli number 5 == string 5)
    === : Tiukka yhtäsuuruus: tyyppienkin täytyy olla samat (5 === 5 = true, 5 === '5' = false) [KÄYTÄ OLETUKSENA]
    != : Erisuuruus: voi muuntaa arvojen tyyppejä ennen vertailua (6 != '5', eli number 6 != string 5 palauttaa true)
    !== : Tiukka erisuuruus: eri tyyppi riittää eroksi (6 !== 5 = true, 6 !== '6' = true)
    > : suurempi kuin
    < : pienempi kuin
    >= : suurempi tai yhtäsuuri kuin, eli vähintään.
    <= : pienempi kuin, tai yhtäsuuri, eli enintään.

sijoitusoperaattorit:
    = : sijoita (Sijoita oikealla oleva arvo vasemmalla olevaan muuttujaan esim. x = 5)
    %= : laske jakojäännös ja sijoita (esim. x %= 3  =  x = x % 3)
    /= : jaa ja sijoita (esim. x /= 3  =  x = x / 3)
    *= : kerro  ja sijoita
    += : lisää ja sijoita (voi myös yhdistää merkkijonoja)
    -= : vähennä ja sijoita
    **= : korota potenssiin ja sijoita

aritmeettiset-, eli laskuoperaattorit:
    % : jakojäännös (esim. 10 % 3 → 1)
    / : jako
    * : kerto
    + : summa (voi myös yhdistää merkkijonoja)
    - : erotus
    ** : potenssiin korotus (esim. 2 ** 3 → 8)

loogiset operaattorit totuusarvojen kuvaamisessa:
    && : JA -palauttaa true vain, kun MOLEMMAT ehdot täyttyvät. (esim. ika >= 18 && ika <= 65)
    || : TAI -palauttaa true, jos vähintään yksi ehto täyttyy. (esim. ika < 18 || ika > 65)
    ! : EI -kääntää totuusarvon vastakkaiseksi. (esim. (ika >= 18) on käännettynä !(ika >= 18))

if + else = jos if lause on false, niin hypätään yli ja suoritetaan else ehto.

TRUTHY & FALSY:
if ei vaadi kirjaimellista boolean-arvoa — JavaScript tulkitsee monia arvoja todeksi tai epätodeksi

FALSY: false, 0, ''(Tyhjä teksti on falsy. Pelkkä välilyönti on kuitenkin truthy), null, undefined ja NaN (virheellisen lukumuunnoksen tulos).
TRUTHY: 'Hei', 42, '0' ja 'false'. Myös tyhjä taulukko [] ja olio {} ovat truthy.
NULLISH COALESCING: a ?? b palauttaa arvon b vain, jos a on null tai undefined. Muuten tulos on a.
TERNARY-OPERAATTORI: ehto ? arvo1 : arvo2, tosi ehto valitsee arvo1:n, epätosi arvo2:n. Ternary sopii lyhyeen kahden vaihtoehdon arvon valintaan. (esim. const status = ika >= 18 ? 'aikuinen' : 'alaikäinen';)
SWITCH: switch sopii tilanteisiin, joissa yhtä arvoa verrataan useisiin tarkkoihin vaihtoehtoihin.

jossa: case määrittää vaihtoehdon. break lopettaa switchin. default suoritetaan, jos mikään case ei vastaa arvoa. Casejä voi olla useampi break pointtiin asti.)

SWITCH vs IF:
SWITCH sopii === tarkkaan vertailuun, jossa case on tarkoin määritelty true or false. Break lopettaa vertailun ja default käsittelee muut arvot.
IF sopii muihin vertailuihin, jossa raja-arvoja (<=) ja yhdistettyjä ehtoja (ika <= 65 && lupa) tutkitaan. Ensimmäinen true ehto määrittää tutkimisen jatkuvuuden ja else käsittelee jäljelle jäävät ehhdot.

Parametri = funktion sisällä käytettävä muuttuja (nimi, valtuutus). Täytetään järjestyksessä! x1, x2, x3... Käytetään määrittelyssä.
Argumentti = kutsun yhteydessä annettu arvo ('Tiia'), käytetään kutsun yhteydessä.
Funktiokutsu = käsky suorittaa funktio annetuilla argumenteilla.

JavaScript Osa 5 - Taulukot:

CONST-LISTA:
const nimet = ['Tiia'];
nimet.push('Aino'); // Taulukkoon saa lisätä nimen.
// Luo ['Tiia'. 'Aino'], mutta varsinainen arvo on 'Tiia'. 'Tiia' on listan nollas jäsen, 'Aino' on listan ensimmäinen jäsen jne...

-Taulukot mahdollistavat datan kompaktimman käsittelyn. Ilman taulukoita jokainen datapiste käsitellään erikseen.
esim.
const nimi1 = 'Aino';
const nimi2 = 'Mika';
const nimi3 = 'Sara';
vs.
const nimet ['Aino','Mika','Sara'];

Taulukossa voi olla useaa tietotyyppiä.
esim.
const tiedot ['Aino', 24, true, {kaupunki: 'Kerava'}]; //{objekti}

indeksi, eli taulukku/array/lista, alkaa nollasta. 
esim. 
const nimet ['Aino','Mika','Sara'];

Aino = 0
Mika = 1
Sara = 2

Alkioita on 3, mutta ensimmäisen alkion indeksi on 0, toinen on 1 ja kolmas on 2.


HAKU:

const ensimmäinen = nimet[0]

nimet = ['Oskari']; //Ei toimi. Se koittaa muokata jo määriteltyä muuttujaa.

const poisto = nimet.shift(); //poistaa taulukon alusta alkion.

console.log(poisto); //palauttaa: 'Oskari'.

FILTER = haku taulukosta

const halututPisteet = esimerkki.filter(
    opiskelija => opiskelija.pisteet >= 70
); 

//jossa: 
-filter() käy taulukon alkiot läpi yksi kerrallaan.
-'opiskelija' on parametri, joka viittaa opiskelija alkioon
-'opiskelija.pisteet' >= 70 on ehto, joka antaa boolean arvon true/false.
-jos true, alkio otetaan mukaan halututPisteet taulukkoon.

TAI

const halututPisteet = esimerkki.filter(
    (opiskelija) => {
        return opiskelija.pisteet >= 70;
    }
)

TAI 

const halututPisteet = esimerkki.filter(
    function halutut(opiskelija) {
        return opiskelija.pisteet >= 70;
    }
)

//jossa: 
-funtion(opiskelija) = opiskelija =>
-ehto funktion {} sisällä = ehto suoraan nuolen => jälkeen
-return-lause = automaattinen palautus 

TAI 

function halutut(opiskelija) {
    return opiskelija.pisteet >= 70;
}

const halututPisteet = esimerkki.filter(halutut); // muuttuja + taulukko + komento + funktio joka toteuttaa toiminnan.
