Token-järjestelmän harjoitus

Tämä sivu toimii jo, mutta CSS sisältää paljon toistuvia arvoja. Tehtäväsi on muuttaa ne selkeäksi token-järjestelmäksi.

Miksi design tokenit?

Kun samat värit, välit ja pyöristykset toistuvat eri komponenteissa, niiden ylläpito vaikeutuu. CSS-muuttujilla yhteiset arvot voidaan nimetä ja hallita yhdestä paikasta.
