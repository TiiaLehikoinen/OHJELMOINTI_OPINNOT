position: relative; (säilyy paikallaan)

-koordinaatit/offset = top, right, bottom, left
static; (säilyy paikallaan) 
fixed; (menee minne määrätään) 
sticky; (normaalivirran mukana aluksi, sitten ei) 
= mahdollistaa päällekkäiset ja liikkumattomat elementit
-z-index = layerit kuvankäsittelyssä. ns. kalvoja päällekkäin.

static = kulkee normaalivirran mukana, default PAITSI jos elementissä on jokin osa määritelty jo ylempänä/alempana.

relative = kulkee normaalivirran mukana, tekee elementistä absolute lapsen containing blocking. hyvä visuaalisiin siirtoihin.

containing block = viewport johon kaikki positioidut elementit suhteutetaan.

fixed = ei kulje normaalivirran mukana, pysyy paikoillaan sivua scrollatessa (esim huomio tai navigointipalkki). suhteessa viewporttiin.

sticky = pysyy normaalisti mukana, kunnes määritelty reuna tulee ja se jää siihen reunaan. Tarvitsee top tai z-index rajan.

absolute = ei kulje normaalivirran mukana, aina siinä mihin määritelty. suhteessa vanhempi elementtiinsä, joka on relative/fixed. (top: 50%; left 50%; transform: translate (-50%, -50%;))

z-index: 0-100 arvoilla. (mitä suurempi arvo, niin sitä pinnemmalla se on.)

inset = offsetin nopeampi versio.
loogiset versiot: 
-inset-block start/end (lohkon alku ja loppu)
-inset-inline-start/end (seuraa tekstin kirjoitus suuntaa)

!!visuaalinen sijainti ei saa rikkoa loogista lukemis ja fokus järjestystä!!

RESPONSIIVINEN SUUNNITTELU:

-joustava perusrakenne, jossa optimoidaan näkymä laiteäytöille.

Työskennellään takaperoisesti: mobiili ensin, muut näytöt sitten.
Lisätään leveimmille näytöille tilaa hyödyntäviä parannuksia. Ei lisätä elementtejä pienentyessä, vain kasvaessa.
Vaihdetaan tyyliä vain hyvästä syystä.

Tarkoitus on suunnitella sivu, joka sopeutuu mihin tahansa näyttöön, ei vain puhelin tai kone.

-Joustavia arvoja: rem, em, fr, %, min(), max(), clamp(), vw, vh 
*Vähentävät kovakoodattujen kokojen tarvetta

Ehdolliset tyylit esim.
.cards {
    display: grid;
    gap: 1rem;
}

@media (min-width: 48rem) { (<--kun tila saavuttaa 48rem, muutos displayssä tapahtuu. Min= vähintään. Max= enintään.)
    .layout {
        grid-template-columns: 16rem 1fr;
    }
} 

@media (width>= 48rem) { 
    .layout {
        grid-template-columns: 16rem 1fr 2fr;
    }
} (>= suurempi kuin tai yhtäsuuri kuin alaraja, < Yläraja , ≤ väli)

width: min (100% - 2rem, 70rem); (<-- 100% miinus 2 rem, mutta ei saa ylittää 70rem.)
margin-inline: auto

font-sixe: clamp; (2rem, 5vw, 4.5rem) = min, väli, max

px ei veny
rivinpituus: ch-yksiköllä. Max-width: 50ch. 1ch on fontikoko 0. Tasavälinen/suhteellinen fontti.
