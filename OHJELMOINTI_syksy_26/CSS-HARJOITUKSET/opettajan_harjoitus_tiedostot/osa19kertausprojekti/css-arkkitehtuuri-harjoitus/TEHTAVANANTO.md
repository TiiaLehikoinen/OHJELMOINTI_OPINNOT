# CSS-arkkitehtuurin refaktorointi – opiskelijan tehtävä

Avaa `opiskelija/index.html` Live Serverillä. Tarkastele kortteja sivupalkissa ja pääsisällössä sekä mobiilissa. **Älä katso malliratkaisua ennen omaa yritystä.**

1. Etsi vähintään viisi ongelmaa tai toistoa CSS:stä ja kirjaa ne.
2. Suunnittele `@layer`-kerrokset ja design tokenit (`:root`-muuttujat).
3. Poista ID-riippuvaiset valitsimet ja tarpeettomat `!important`-määreet.
4. Muuta kortin `@media (min-width:900px)` -sääntö container queryksi. Muista, että kyselysäiliö on kortin esi-isä.
5. Korjaa vähintään yksi saavutettavuus- tai responsiivisuusongelma (esim. fokus, tekstin kontrasti, kiinteä korkeus, ylivuoto).
6. Testaa 320px, 390px ja leveä työpöytänäkymä, 200% zoom ja Tab-näppäin.
7. Täytä `MUUTOSLOKI.md`: ennen / jälkeen / miksi / miten testasit.

**Palauta:** index.html, styles.css ja MUUTOSLOKI.md.
